# Changelog

## 1.0.0

- Initial release of Cozy Vintage.
- Added **Cozy Vintage Dark** variant: deep warm brown / muted charcoal background with soft vintage syntax colors.
- Added **Cozy Vintage Light** variant: warm cream editor background with the shared vintage syntax palette.
- Shared syntax mapping: keywords (muted lavender), functions (dusty blue), strings (warm cream / soft golden), variables (soft brown-gray), numbers & constants (vintage rose brown), classes & types (blue-purple), comments (low-contrast warm gray-brown).
